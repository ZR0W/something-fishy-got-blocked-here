Help

  • Patterns: example.com = the domain and all its subdomains · =example.com = exactly that host · *.example.com = subdomains only. Optional path is a prefix, e.g. /r/news.
  • Placeholders: {host}, {url}, {count}, {time}.
  • Time of day: leave both times empty for "any time", or set both. The first message whose window contains the current time is used; windows may wrap past midnight (23:00 → 05:00). If no message in a rule fits, the default messages are used.

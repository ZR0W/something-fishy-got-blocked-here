Something Fishy 🐟

Messages shown when your DNS blocks a site. Everything here stays in this browser (storage.local).

DNS over HTTPS was used on . With DoH on, Firefox bypasses Pi-hole, so blocked sites load and this extension never triggers. Turn it off in Settings → Privacy & Security → DNS over HTTPS.

What to show

One entry that fits the current time is picked at random each time. Entries with a time window take over while their window is open.

Per-site rules

The first enabled rule that matches is used, top to bottom.

Help

        
    
          
  • Patterns: example.com = the domain and all its subdomains ·
            =example.com = exactly that host · *.example.com = subdomains only.
            Optional path is a prefix, e.g. /r/news.
    • 
          
  • Placeholders: {host}, {url}, {count},
            {time}.
    • 
          
  • What to show: each entry is a message page, a web page of your choice
            (placeholders in its address are URL-encoded; LeechBlock's $U works too), a
            blank page, or close the tab. If your web page is blocked as well, the message page
            is shown instead.
    • 
          
  • Time of day: leave both times empty for "any time", or set both; windows may wrap past
            midnight (23:00 → 05:00). Each time, one entry is picked at random among those that fit, and
            entries with a time window win while it's open. If nothing in a rule fits, the default entries
            are used.
